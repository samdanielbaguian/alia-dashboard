HOW IT WORKS
================================================================================

1. USER LOGS IN
   ↓
2. SYSTEM STORES JWT + USER OBJECT (with role)
   ↓
3. USER NAVIGATES TO /dashboard
   ↓
4. APP DETECTS ROLE FROM localStorage
   ↓
5. REDIRECTS TO:
   • /dashboard/merchant (if merchant)
   • /dashboard/customer (if customer)
   ↓
6. SIDEBAR & PAGES UPDATE BASED ON ROLE

AUTHENTICATION FLOW
================================================================================

LOGIN:
   POST /login → JWT token + user object
   ↓
STORE:
   localStorage.authToken = "jwt..."
   localStorage.authUser = { role: "merchant", ... }
   ↓
ACCESS PROTECTED ROUTES:
   Include header: Authorization: Bearer {token}
   ↓
ERROR HANDLING:
   401 → Redirect to /login
   Clear localStorage
   User must login again
